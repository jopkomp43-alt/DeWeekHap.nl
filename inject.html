🚀 DeWeekHap Taalswitch & Fixes

⚡ Snelle Activatie (Klik & Klaar)

Klik op de knop hieronder om de fixes tijdelijk te activeren op de huidige pagina:

📌 Stap 1: Open de Website

Ga naar deweekhap.nl

📝 Stap 2: Open Browser Console

  • Chrome/Edge: Druk op F12 of Ctrl+Shift+J
  • Firefox: Druk op F12 of Ctrl+Shift+K
  • Safari: Druk op Cmd+Option+C

⚙️ Stap 3: Plak Deze Code

Kopieer en plak deze code in de console:

const s=document.createElement('script');s.src='https://deweekhap.nl/loader.js';document.body.appendChild(s);console.log('✅ DeWeekHap fixes geladen!');

🔖 Permanente Oplossing

Voeg deze regel toe aan index.html vlak voor </body>:

<script src="loader.js"></script>

✅ Dit laadt automatisch de taalswitch en fixes bij elke pageload!
